# TASK ARCHIVE: Bind Oxlint into CI, local lint, and pre-commit

## SUMMARY

Local `pnpm lint` now runs `oxlint --fix`. Husky pre-commit and CI run `pnpm lint:check` (`oxlint`, no `--fix`). `prepare: husky` installs hooks on a normal `pnpm install`. CI install sets `HUSKY=0`. CONTRIBUTING and techContext no longer say lint is optional / not in CI. Tracked as [#162](https://github.com/Texarkanine/a16n/issues/162). Follow-up to [#74](https://github.com/Texarkanine/a16n/issues/74) after leftover unused-vars `#156`–`#161` merged.

## REQUIREMENTS

1. Local `pnpm lint` autofixes (`oxlint --fix`).
2. Check-only command for hook and CI (`oxlint` without `--fix`).
3. Pre-commit hook installs on `pnpm install` (pnpm `prepare`, not npm-only).
4. Pre-commit checks only; must not `--fix`.
5. CI runs check-only and fails on leftover correctness errors.
6. Do not enable extra Oxlint categories beyond `.oxlintrc.json` from #74.
7. No change-detector tests for script strings, workflow YAML, or CONTRIBUTING prose. Prefer a standard hook tool over a custom installer.
8. Update CONTRIBUTING and techContext so lint is no longer optional / not in CI.

## IMPLEMENTATION

`husky@^9.1.7` plus `"prepare": "husky"`. Root scripts: `"lint": "oxlint --fix"`, `"lint:fix": "oxlint --fix"` (alias), `"lint:check": "oxlint"`. `.husky/pre-commit` is one line: `pnpm lint:check`. `.github/workflows/ci.yaml` runs `pnpm lint:check` after install; install sets `HUSKY: "0"`. Docs: `CONTRIBUTING.md`, `memory-bank/techContext.md` (worktree installs: `HUSKY=0 pnpm install` so husky does not write shared `core.hooksPath`). `.oxlintrc.json` unchanged. `turbo.json` unused `"lint": {}` left as-is.

Chose husky over `simple-git-hooks` (would overwrite a shared `.git/hooks/pre-commit`) and over a custom installer.

## TESTING

No new Vitest cases (operator + #74: mapping lint scripts is not a TDD unit; Oxlint is the checker). `pnpm lint:check`, `pnpm exec oxlint`, and `pnpm lint` exit 0. Hook and CI have no `--fix`. `pnpm test` 17/17. `/niko-preflight` PASS. `/niko-qa` PASS.

## LESSONS LEARNED

- In a git worktree, husky 9.1.7 `git config core.hooksPath .husky/_` writes the **shared** parent `.git/config`, not worktree-local config, and would bypass machine-local `.git/hooks`. Unset after the plan spike. Use `HUSKY=0` when installing in a shared-`.git` worktree.
- `simple-git-hooks` would overwrite that same shared `pre-commit` file.
- Husky 9.1.7 runs `.husky/pre-commit` via `sh -e`; a one-line `pnpm lint:check` is enough (do not source `_/husky.sh`).
