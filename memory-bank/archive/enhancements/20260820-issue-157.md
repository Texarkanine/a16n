## IMPLEMENTATION

- `packages/cli/test/create-program.test.ts` — unused `afterEach` import
- `packages/cli/test/commands/convert.test.ts` and `discover.test.ts` — unused `CommandIO` type imports
- `packages/cli/test/git-ignore.test.ts` — unused `GitIgnoreResult` and `IgnoreSource` type imports
- `packages/cli/test/integration/integration-split-dirs.test.ts` and `integration-path-rewrite.test.ts` — unused `fixturesDir` plus the now-unused `fixturesDirFor` import
- `packages/cli/test/e2e/cli-convert.test.ts` (two cases), `cli-from-to-dir.test.ts`, and `cli-gitignore.test.ts` — unused `stdout` destructure bindings

Bindings were removed rather than prefixed with `_`. The `--verbose --json` e2e case that still asserts on `stdout` was left intact.

## LESSONS LEARNED

- `oxlint --fix` does not remove unused type imports or unused destructure bindings.
- Deleting an unused `fixturesDir` also requires dropping `fixturesDirFor` in the same edit, or Oxlint reports a replacement unused-var.
- Leftover unused-var tickets should treat Oxlint as the tester. New tests would be change-detectors.
- Isolated worktrees need `pnpm install` and `pnpm build` before `pnpm --filter a16n test`, because that filter does not run Turbo's `test` → `build` edge.

## PROCESS IMPROVEMENTS

When verifying leftover-oxlint tickets in a fresh worktree, build first. `pnpm --filter <pkg> test` is not equivalent to Turbo `pnpm test --filter <pkg>`.
